# Tristan Phillips Accounting

Website for Tristan Phillips Accounting, bookkeeping for Pennsylvania real estate agents.

One page (`index.html`), no build step, hosted on GitHub Pages.

## Editing

- Contact details are in the `CONFIG` block at the bottom of `index.html` (email and Calendly link).
- To add a photo, save it as `tristan.jpg` next to `index.html` and follow the comment above the "TP" portrait in the About section.
- Push to `main` and GitHub Pages republishes in a minute or two.

Later you can buy a domain (about $12/year) and point it at GitHub Pages.
